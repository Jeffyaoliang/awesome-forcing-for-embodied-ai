# Contributing

Submit primary paper/arXiv URL, official code link where available, intervention mechanism, supervision target, evaluation protocol, release status, and evidence provenance.

Verification tags: `candidate` (unverified discovery), `pending` (source check needed), `reviewed` (primary material checked), `executed` (code actually run), `reproduced` (metric replicated with logs and protocol).

Please do not invent code URLs or treat author-reported metrics as replicated.
